The project consisted of 3 phases:

- Data Collection: Development of a Scrapy-based crawler to aggregate large-scale listings from Belgian real-estate websites
- Exploratory Data Analysis: Led a 4-person team to uncover market trends and price dynamics, ensuring data quality and alignment for the modeling phase.
- ML & Deployment: Developed a regression model to predict Belgian property prices, utilizing Optuna for automated hyperparameter tuning.
  Built a FastAPI backend to serve model predictions and a Gradio web interface for user interaction.
